# GrantLens

A Source-Grounded Grant Research Assistant

## Overview

GrantLens is an applied AI portfolio project designed
to help nonprofit researchers explore publicly available
grant information using natural-language questions.

The application will retrieve relevant public records
and generate answers supported by verifiable sources.

## Objectives

- Collect and structure public grant records.
- Build a searchable grant database.
- Implement source-grounded retrieval.
- Generate answers with citations.
- Evaluate retrieval and answer quality.

## Project Status

Phase 1: Project setup and planning.

## Responsible Use

This is an independent portfolio demonstration.
It is not an official Mott Foundation application
and does not make funding recommendations.
